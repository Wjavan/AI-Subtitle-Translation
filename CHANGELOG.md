# Changelog

## [1.0.0] - 2026-09-12

- Initial release
- Multi-platform LLM API support (OpenAI, DeepSeek, Qwen, GLM, Gemini, Ollama, etc.)
- Context-aware subtitle translation with 80+ languages
- Hallucination detection and echo detection
- Prompt caching and context caching for cost optimization
- Compatible with reasoning models (DeepSeek-R1, QwQ, etc.)
- Local/offline translation support via Ollama
